[h1]俘虏不只是牢房里的负担。他们可以是一笔赎金、一场交换、一次停火，或下一场战争的导火索。[/h1]

[b]Prisoner Diplomacy（战俘外交）[/b]将 RimWorld 的俘虏系统扩展为完整的谈判、派系记忆与后果机制。

[b]当前版本：1.2.0[/b]，支持 RimWorld 1.6。

敌对派系可能主动来信要求赎回成员；玩家也可以通过原版通讯台主动提出条件。俘虏的身份、健康、重要性、派系资源、谈判者的社交技能，以及你过去如何对待该派系，都会影响交易。

[h2]你可以谈判什么？[/h2]
[list]
[*]白银、符合派系特点的物资或好感
[*]用一名俘虏交换被绑架的殖民者
[*]持续 5 至 30 天的临时停火
[*]针对符合条件的袭击获取一次性预警情报
[*]组合多种合法报酬，并处理结构化还价
[*]由种族适配器与扩展模组注册的特殊物品报酬和额外事件
[/list]

[h2]与其他俘虏／外交模组有什么不同？[/h2]

现有模组大多专注于单次白银赎金、一对一换俘或宏观派系战争。Prisoner Diplomacy 则以具名 Pawn 为核心，将其扩展为可追踪、会产生后果的战俘外交流程。

从提出条件、还价、实际释放和安全离图，到付款、派系记忆与后续事件，每一步都由游戏状态验证。AI 只增添派系个性，不会取代规则。

派系物资会随科技等级扩展，从药品与食物到工业／太空时代材料；其他模组物品只能通过公开适配器 API 成为特殊报酬。

派系储备有限；要求过高可能导致拒绝、还价、冷却期或暂时停止谈判。

[h2]接受条件不等于立即付款[/h2]

每笔交易都由确定性的游戏规则处理。接受协议后，你仍必须对正确的俘虏使用专用释放命令，并让他通过原版释放流程安全离开指定地图，报酬才会开始履行。

[list]
[*]死亡、逃脱、招募、奴役、出售或错误释放都可能使协议失效
[*]受伤俘虏无法旅行时，实际完成的医疗照护可以延长期限
[*]一次性发放保护会阻止存档和读档造成重复付款
[*]跨殖民地交易会追踪指定地图和目标俘虏
[/list]

[h2]派系会记住你的所作所为[/h2]

每个派系都会形成对你可靠程度、俘虏待遇和累积怨恨的独特印象。医疗照护、履行协议和无条件释放可以改善这种记忆；摘取器官、虐待、违约和处决可能留下长期后果。

海盗交易尤其危险。付款可能延迟，俘虏可能被煽动越狱，救援部队可能抵达，或者交换完成后发生伏击。风险会在释放前公开，你可以接受风险、取消交易，或用较低报酬换取更安全的条件。

[h2]不只有赎金提议[/h2]
[list]
[*]带有实体商队交接的中立世界地图交易点
[*]假投降与渗透行动
[*]公开战争罪审判
[*]重要俘虏救援行动与死亡报复
[*]赎金伏击及后续后果
[*]临时停火和一次性袭击预警情报
[/list]

外交界面将案件、协议、历史和事件视图分开。即使某个派系当前没有俘虏，你仍可以返回查看停火剩余时间、可用情报和过去的交易。

[h2]可选的 AI 派系回复[/h2]

AI 默认关闭，游玩本模组也完全不需要 AI。启用后，它可以根据派系人设、意识形态、战斗伤势、人际关系、历史恩怨和玩家的简短留言，生成更有辨识度的派系回复。

[b]AI 文本默认仅用于叙事。[/b]正式条件、付款、期限、Pawn 状态和事件结果仍由确定性的游戏代码负责。另有独立选择可为尚未接受的还价提供有限建议，但结果仍由核心验证。

没有 AI 服务商时，Prisoner Diplomacy 会使用完整的本地化标准回复，并继续离线运行。

[h2]面向 Mod 作者的扩展 API[/h2]

本模组提供版本化的公开 API，支持种族和派系适配器、特殊 `ThingDef` 报酬、派系人设以及事件元数据。核心负责验证价格、物资上限、存档持久化、俘虏释放和一次性履行。请阅读 `PrisonerDiplomacyApi.md`、`Docs/RewardCatalog.md` 和 `Docs/AddonQuickstart.md` 来制作扩展模组。

[h2]隐私优先的错误回报[/h2]

匿名错误回报是可选且需要同意。你可以只发送本次、允许本次游戏、以后始终发送或拒绝；持久同意可在设置中撤销，选择前不会上传。

回报会经过清理、在后台异步发送，且不会修改安装内容。可能包含错误／版本、匿名交易状态和启用模组 Package ID，但不会主动收集存档、Pawn、殖民地、硬件 ID 或 API 密钥；系统会尽量移除路径和秘密信息。

详细回报 30 天后删除，汇总和修复审计数据 180 天后删除。正式 AI 分析已启用：样本会先发送至 Gemini 3.7 Flash，只有高置信度内部问题才会发送至 AI-HUB（`ai.aiyuhub.com`）生成 GPT 5.6 Sol 修复候选。供应商故障不会影响游戏。详见 Docs/TelemetryPrivacy.md。

[h2]需求与兼容性[/h2]
[list]
[*][b]RimWorld 1.6[/b]
[*][b]需要 Harmony[/b]，并应加载在 Prisoner Diplomacy 之前
[*]RimChat、Humanoid Alien Races、Hospitality、Combat Extended 以及其他种族或派系模组都是可选整合
[*]核心模组不依赖 AI 或 RimChat
[*]包含 English、繁体中文、简体中文、日本語和한국어本地化
[/list]

旧交易数据会进行保守迁移，但在进行大型模组更新前仍建议备份重要存档。

[h2]问题回报[/h2]

开启开发者模式并使用 [b]Prisoner Diplomacy → Copy diagnostic report[/b]。请附上交易阶段、当前模组列表和相关 Player.log 片段。切勿公开 API 密钥。

[b]俘虏可以是财产，也可以是人质；从现在开始，他们也可能成为一场外交危机。[/b]

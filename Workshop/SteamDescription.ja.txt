[h1]囚人は独房の重荷であるだけではありません。身代金、捕虜交換、停戦、そして次の戦争の火種にもなり得ます。[/h1]

[b]Prisoner Diplomacy（戦俘外交）[/b]は、RimWorld の囚人を交渉、派閥の記憶、結果を含む外交システムへ拡張します。

[b]バージョン 1.2.0[/b]（RimWorld 1.6）。敵対派閥からの連絡、またはバニラの通信台から交渉を開始できます。囚人の身分、健康、重要度、派閥資源、交渉役の社交スキル、過去の対応が取引を左右します。

[h2]交渉できるもの[/h2]
[list]
[*]シルバー、派閥の物資、好感度
[*]捕虜と誘拐された入植者の交換
[*]5～30日間の一時停戦
[*]条件を満たす襲撃への一度限りの早期警戒情報
[*]複数報酬の組み合わせとカウンターオファー
[*]アダプターやアドオンが登録する特殊報酬と追加イベント
[/list]

[h2]他の囚人・外交 MOD との違い[/h2]

既存の MOD は、一度限りのシルバー身代金、一対一の捕虜交換、または大規模な派閥戦争に重点を置くことが多いでしょう。Prisoner Diplomacy は身代金と捕虜交換を、名前を持つ個々のポーンを中心とした、追跡可能で結果の残る捕虜外交フレームワークへ拡張します。

要求とカウンターオファーから、実際の解放とマップからの安全な退出、支払い、重複報酬の防止、派閥の記憶、後続イベントまで、すべて検証済みのゲーム状態として管理されます。AI は派閥らしい返信を追加しますが、このルールを置き換えません。

物資は技術階層に応じて増えます。低技術の医薬品・食料から、工業／スペーサーの医薬品、部品、燃料、スチール、布、先進素材まで選べます。他 MOD のアイテムは公開アダプター API 経由でのみ特殊報酬になります。派閥の備蓄は有限で、過大な要求は拒否、再交渉、クールダウン、交渉停止につながります。

[h2]受諾しても即時支払いではありません[/h2]
契約は決定論的に処理されます。正しい囚人に専用の解放命令を使い、バニラの解放手順で指定マップから退出させて初めて履行されます。
[list]
[*]死亡、脱走、勧誘、奴隷化、売却、誤った解放は契約を無効化
[*]負傷囚人への実際の医療ケアは期限を延長する場合があります
[*]セーブ／ロードによる重複報酬を防止
[*]複数植民地の取引でもマップと対象囚人を追跡
[/list]

[h2]派閥はあなたを覚えています[/h2]
治療、契約履行、無条件の解放は信頼を改善します。臓器摘出、虐待、違約、処刑は長期的な遺恨を残します。海賊との取引では支払い遅延、脱走工作、救援、交換後の待ち伏せが起こり得ます。リスクは解放前に表示されます。

[h2]身代金以外のイベント[/h2]
[list]
[*]中立ワールドマップ交換地点とキャラバン引き渡し
[*]偽装降伏と潜入、公開戦争犯罪裁判
[*]重要囚人の救出と死亡への報復
[*]身代金の待ち伏せ、停戦、襲撃早期警戒
[/list]
案件、協定、履歴、イベントは別ビューで確認できます。派閥に現在の囚人がいなくても、停戦残り時間、情報、過去の取引を閲覧できます。

[h2]任意の AI 派閥返信[/h2]
AI はデフォルトで無効で、プレイに必須ではありません。有効時は派閥のペルソナ、思想、負傷、人間関係、因縁、プレイヤーの短いメモから返信を作ります。

[b]AI テキストはデフォルトでは物語表現のみです。[/b]条件、支払い、期限、Pawn 状態、イベント結果はゲームコードが管理します。高度なオプトインでは未受諾のカウンターオファーへの限定助言を許可できますが、備蓄、在庫、合法報酬、古いコンテキストに対して再検証されます。AI プロバイダーなしでも完全ローカライズでオフライン動作します。

[h2]MOD 作者向け拡張 API[/h2]
バージョン管理された公開 API で、種族／派閥アダプター、特殊 `ThingDef` 報酬、ペルソナ、イベントを登録できます。コアが価格、上限、セーブ、解放、一度きりの履行を検証します。`PrisonerDiplomacyApi.md`、`Docs/RewardCatalog.md`、`Docs/AddonQuickstart.md` を参照してください。

[h2]プライバシー優先のエラー報告[/h2]
匿名報告は任意です。受信サーバー、設定、関連エラーが揃った時だけ同意ダイアログを表示し、選択前は何も送信しません。同意は撤回できます。本番受信サーバーとオプトイン試験は検証済みで、報告はサニタイズされた非同期送信となり、インストールを変更しません。

報告にはエラー、バージョン、匿名取引状態、アクティブ MOD の Package ID が含まれる場合があります。セーブ、Pawn、コロニー、ハードウェア ID は意図的に収集しません。詳細報告は30日、集計・修復監査データは180日で削除されます。AI 分析は現在無効です。将来有効化された場合、Google Gemini 3.7 Flash の後、高確度の内部問題だけを AI-HUB（`ai.aiyuhub.com`）へ送り GPT 5.6 Sol の修正候補を作成します。詳細は Docs/TelemetryPrivacy.md を参照してください。

[h2]必要条件と互換性[/h2]
[list]
[*][b]RimWorld 1.6[/b]
[*][b]Harmony 必須[/b]（Prisoner Diplomacy より前にロード）
[*]RimChat、Humanoid Alien Races、Hospitality、Combat Extended などは任意連携
[*]コアは AI や RimChat に依存しません
[*]英語、繁体字／簡体字中国語、日本語、韓国語に対応
[/list]

[h2]問題の報告[/h2]
開発者モードの [b]Prisoner Diplomacy → Copy diagnostic report[/b] を使い、取引段階、MOD リスト、Player.log の抜粋を添付してください。API キーは公開しないでください。

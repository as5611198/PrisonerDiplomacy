[h1]戰俘外交：示範擴展模組[/h1]

這是一個可實際遊玩、附完整原始碼的 [b]Prisoner Diplomacy 1.2 公開 API[/b] 示範 Add-on，與核心模組 1.2.1 版本相容。你可以訂閱後直接看擴展系統如何在遊戲中運作，也可以參考原始碼與範本，製作自己的種族、派系、特殊報酬、Persona 或 UI 整合。

[b]本 Add-on 是選用內容。[/b]一般 Prisoner Diplomacy 玩家不需要安裝。

[h2]玩家安裝後會得到什麼？[/h2]

[list]
[*]低科技派系可提供 2 枚[b]外交印信[/b]作為特殊報酬。
[*]工業／太空派系可提供 1 份[b]加密外交帳冊[/b]。
[*]原版人類提供 +10 外交價值範例；帝國俘虜再額外 +25。
[*]帝國、海盜與部落派系具有不同的敘事 Persona 範例。
[*]交涉 Header 會顯示一條精簡、唯讀的 Adapter 資訊列。
[*]公開 API Inspector 可查看俘虜、派系、交易、報酬、註冊與事件快照，不會修改它們。
[*]開發者模式提供快照、Context、條件預覽與完整報告工具。
[/list]

[h2]Modder 可以學到什麼？[/h2]

[list]
[*][code]IPrisonerDiplomacyExtension[/code] 註冊與 API 版本防護。
[*]依種族／派系／科技層級判斷的 Context Adapter 與有限價值修正。
[*]由核心驗證、可安全存檔且只發一次的自訂 ThingDef 報酬。
[*]只影響敘事、不改變遊戲數字的派系 Persona Provider。
[*]API 1.2 四種事件家族的 Metadata 範例。
[*]唯讀快照、[code]PreviewDemand[/code] 與 UI Extension 區域。
[*]診斷、本地化一致性、建置、驗證、部署與打包腳本。
[/list]

[h2]重要 API 邊界[/h2]

Prisoner Diplomacy 是唯一交易權威。本 Add-on 不會釋放／轉移 Pawn、改寫／完成交易、自行生成談妥報酬、修改派系儲備或呼叫私有事件排程器。

API 1.2 的外部事件定義是可發現的目錄 Metadata；註冊[b]不等於[/b]排程或執行核心事件。完全自訂事件必須把狀態留在自己的 Add-on，直到公開 Scheduler／Executor 契約推出。
